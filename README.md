# Campus Event Hub – Responsive College Event Discovery & Registration Website

## Overview
Campus Event Hub is a first-year B.Tech CSE Web Development mini-project built using **HTML5**, **CSS3**, and **Vanilla JavaScript (ES6+)** with no external frameworks or backend dependencies.

## Features
- **Home Page (`index.html`)**: Responsive navigation bar, hero introduction, key highlights, and dynamically rendered featured events.
- **Events Page (`events.html`)**: 8 sample campus events with real-time title search, category filtering, sorting, and an empty-state message.
- **Event Details Page (`event-details.html`)**: Dynamically loads full event details (date, time, venue, organizer, description, eligibility) using URL parameters (`?id=`).
- **Registration Page (`registration.html`)**: Client-side JavaScript form validation and browser-based demo persistence using `localStorage`, plus a "My Registrations" summary panel.
- **About Page (`about.html`)**: Project purpose, problem statement, objectives, and technology overview.
- **Contact Page (`contact.html`)**: Student helpdesk details and a validated contact form.

## How to Run
1. Download or extract the `CampusEventHub` folder.
2. Double-click `index.html` to open it in any modern browser (Chrome, Edge, Firefox, Safari).
3. No server, database, or installation is required.

## Academic Scope Disclaimer
This application is a frontend prototype created for academic demonstration. Registration entries are stored locally in the user's browser (`localStorage`) and are not transmitted to any university server or database.

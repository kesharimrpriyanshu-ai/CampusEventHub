About Campus Event Hub

Learn about the purpose, objectives, and core web technologies powering this student mini-project.

What is Campus Event Hub?

Campus Event Hub is a responsive frontend web application designed as a first-year B.Tech CSE Web Development mini-project. It provides students with a single, organized web portal to browse upcoming campus events, search and filter by category, read full event details, and submit a validated demo registration form.

Problem It Solves

On most college campuses, event announcements are scattered across noticeboards, informal chat groups, and printed posters. As a result, students often miss hackathons, workshops, or cultural activities or struggle to find basic details like venue, time, and eligibility. Campus Event Hub addresses this by presenting structured event cards with instant search and category filters in one clean interface.

Main Objectives

  • Provide a clean, accessible, and responsive website that works smoothly on desktop, tablet, and mobile screens.
  • Allow students to discover events quickly using live title search, category filtering, and sorting.
  • Display complete event details including schedule, venue, organizer, description, and eligibility.
  • Demonstrate client-side JavaScript form validation and browser-based data persistence using localStorage.
  • Keep the codebase clean, modular, and easy for beginners to understand and maintain without external frameworks.

Technologies Used

HTML5

Semantic page structure using header, nav, main, section, article, aside, form, and footer elements.

CSS3

Custom properties, Flexbox, CSS Grid, responsive media queries, card layouts, and subtle hover transitions.

Vanilla JavaScript (ES6+)

DOM manipulation, event listeners, Array.filter(), dynamic HTML rendering, form validation, and localStorage.

Project Scope Note: This is strictly a client-side academic prototype. It does not use a backend server, database, payment gateway, or live university authentication system.
